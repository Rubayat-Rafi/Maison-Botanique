# Maison Botanique

Maison Botanique is a botanical skincare storefront designed to make discovering and shopping for everyday skincare feel calm and simple. The site pairs an editorial, nature-inspired presentation with product information and the core flows of an online shop.

## Website features

- A homepage with featured products, skincare categories, ingredient highlights, brand values, testimonials, and a newsletter section.
- A shop with product listings and category browsing.
- Product detail pages with descriptions, ingredients, sizes, and prices.
- A shopping cart and checkout flow.
- Account pages for sign-up, login, profile management, and order history.
- About, contact, privacy, and terms pages.
- Responsive layouts for desktop and mobile screens.

## Built with

- React and TypeScript
- Vite
- Tailwind CSS and shadcn/ui components
- React Router
- Supabase client integration

## Run locally

From this directory, install dependencies and start the development server:

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```
